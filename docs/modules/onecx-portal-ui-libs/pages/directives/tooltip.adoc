= OneCX Tooltip Directive

:idprefix:
:idseparator: -

[#overview]
== Overview
The `OcxTooltipDirective` (`ocxTooltip`) from `@onecx/angular-accelerator` extends the PrimeNG tooltip. It shows the tooltip on hover and focus, links the tooltip to its host via `aria-describedby` and closes the tooltip with the `Escape` key. All inputs of the PrimeNG tooltip, e.g. `tooltipPosition` or `tooltipOptions`, can be used as well.

[source, html]
----
<button type="button" [ocxTooltip]="'Save the changes'" tooltipPosition="top">Save</button>
----

[#inputs]
== Inputs

[cols="1,1,1,3"]
|===
| Name | Type | Default | Description

| `ocxTooltip` | `string \| TemplateRef<HTMLElement> \| undefined` | `undefined` | Content of the tooltip. If empty, no tooltip is shown.
| `ocxTooltipCursor` | `string \| null \| undefined` | `'pointer'` | CSS cursor applied to the host element while a tooltip text is set. Not set or `undefined`: `pointer` is applied. Any CSS cursor value, e.g. `default` or `help`: that value is applied instead. `null`: the directive does not set or remove the cursor style, so the host's own styling applies.
|===

[#cursor]
== Cursor
By default, the directive applies `cursor: pointer` to its host as an inline style. A pointer cursor signals that an element is clickable. On elements that do nothing when clicked, e.g. labels or icons, use `ocxTooltipCursor` to apply a fitting cursor instead:

[source, html]
----
<!-- Use the default cursor -->
<span [ocxTooltip]="'Additional information'" ocxTooltipCursor="default">Label</span>

<!-- Keep the cursor defined by the host's own styles -->
<span class="my-label" [ocxTooltip]="'Additional information'" [ocxTooltipCursor]="null">Label</span>
----

The data table column header labels with a tooltip use `cursor: default`.
