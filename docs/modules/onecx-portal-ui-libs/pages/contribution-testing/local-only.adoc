[#local-only-testing]
= Local-only Testing

If a change is fully covered by the library's own unit tests — for example a pure logic fix with no UI surface — verify it in the *onecx-portal-ui-libs* repository alone. No shell, no application, no local OneCX environment is required.

[#running-the-tests]
== Running the tests

. Run the unit tests. The repository root exposes an `nx` test target that runs the tests of the affected projects:
+
[source, bash]
----
npm test
----

. If the change affects how a component looks or behaves, also open the Storybook for the affected library to inspect it manually. Every Angular library exposes a `storybook` `nx` target:
+
[source, bash]
----
nx run <library>:storybook
----
+
For example, to open the Storybook of `angular-accelerator`:
+
[source, bash]
----
nx run angular-accelerator:storybook
----

[#next]
== When the change needs more than the library's own tests

If the change has to run inside the OneCX Shell and one or more local applications, continue with the {integration_testing}[Integration testing] guide. If it is confined to a single OneCX application, use the {application_only_testing}[Application-only testing] guide.
