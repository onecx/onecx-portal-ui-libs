[#required-package-updates]
= Required Package Updates

If the following packages are used in your project, update them to ensure compatibility with Angular 22 and OneCX UI libs v9:

[cols="2,2,3"]
|===
| Package | Required Version | Notes

| `@onecx/*`
| `^9.x.y`
| Upgrade all used OneCX UI libraries from v8 to v9

| `@angular/*`
| `^22.1.4`
| Minimum Angular version required by `@openng/optimus-ui` v2

| `typescript`
| `>=6.0 <6.1`
| Required by the Angular 22 compiler

| `nx`, `@nx/*`
| `>=23.1.0`
| Only for NX workspaces; first NX version that supports Angular 22

| `@ngrx/*`
| `^22.0.0`
| Required when using `@onecx/ngrx-accelerator` or `@onecx/ngrx-integration-interface`

| `@openng/optimus-ui`
| `^2.0.2`
| Replaces `primeng`; required by `@onecx/angular-accelerator`, `@onecx/angular-utils`, `@onecx/angular-standalone-shell` and `@onecx/angular-testing`

| `@openng/optimus-ui-themes`
| `^2.0.2`
| Replaces `@primeng/themes`; required by `@onecx/angular-utils`

| `@openng/optimus-ui-styled`
| `^2.0.2`
| Replaces `@primeuix/styled`; required by `@onecx/angular-utils`

|===

The `primeng`, `primeicons`, `@primeng/themes`, `@primeuix/*` and `primelocale` packages are no longer used by the OneCX UI libraries. The complete replacement mapping and the automated migration are described in xref:./migrate-to-optimus-ui.adoc[Migrate from PrimeNG to Optimus UI].

[#installation-commands]
== Installation Commands

Run this command to update the supporting packages:

[source, bash]
----
npm install @openng/optimus-ui@^2.0.2 \
  @openng/optimus-ui-themes@^2.0.2 \
  @openng/optimus-ui-styled@^2.0.2

npm install @ngrx/<package-name>@^22

npm install @onecx/<package-name>@^9
----
