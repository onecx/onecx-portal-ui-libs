= Verify the post-v9 behavior changes

After the v9 libraries bump, verify the following behavior changes. None of them require a code change by default, but each one is worth an explicit check during your smoke test.

== Accessibility: one results announcement per search, filter, or sort

Data-driven components announce search, filter, and sort results to screen readers through `ResultsAnnouncementService`. The v9 line announces **one** results announcement per search, filter, or sort action, and **none** at initial load. If your application overrides or extends the results-announcement behavior, verify that a search, filter, or sort produces exactly one announcement and that the initial load is silent.

== DataTable row grouping and column-header tooltips (v9.1.0)

The DataTable supports basic row grouping and column-header tooltips from v9.1.0. If your application uses row grouping or column-header tooltips, verify both render as expected.

== `p-select` autofocus fixes (v9.3.0)

The v9.3.0 line includes `p-select` autofocus fixes. If your application relies on `p-select` receiving focus automatically, verify the focus behavior in your flows.

== `OcxTooltipDirective` cursor configurability (v9.3.0)

The v9.3.0 line makes the cursor of the `OcxTooltipDirective` configurable. Verify the cursor behavior of your tooltips after the bump.

== Change detection is now explicit

The Angular 21→22 update makes change detection explicit. Where a component previously had no change-detection strategy, it now opts into `ChangeDetectionStrategy.Eager` explicitly. **The behavior is unchanged** — the intent is simply to make the strategy explicit. This is part of the Angular 21→22 update described in the official https://angular.dev/update-guide?v=21.0-22.0[Angular migration guide], not a change made by the OneCX UI libraries.
