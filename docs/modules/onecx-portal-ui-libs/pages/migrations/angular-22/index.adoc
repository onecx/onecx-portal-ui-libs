= Migrate OneCX App from Angular 21 to Angular 22

:idprefix:
:idseparator: -

[#overview]
== Overview

This guide provides step-by-step instructions for migrating OneCX applications from Angular 21 to Angular 22.
As part of upgrading to Angular 22, the OneCX UI libraries must be updated to version 9.

OneCX UI libraries v9 change the component library the `@onecx/*` libraries are built on: from **PrimeNG** to **Optimus UI**, an open-source, community-maintained fork of PrimeNG that preserves the PrimeNG API. The reason for the move is that PrimeNG is no longer open source and is not compatible with the Angular 22 build; moving to Optimus UI keeps the OneCX libraries fully open source while letting consuming apps change little — the same PrimeNG-style selectors, inputs, and providers keep working. PrimeFlex is replaced by **Tailwind CSS v4** at the same time.

[NOTE]
====
This is the Angular 22 / v9 migration. A separate, later effort moves OneCX's own components to Angular Material + Tailwind CSS with Angular 23 support — see the xref:migrations/angular-23/migration-plan.adoc[Angular 23 migration guide].
====

[#prerequisites]
== Prerequisites

Before starting this migration:

* The OneCX application is currently running on Angular 21
* The OneCX UI libraries v8.x are installed
* The application builds and the tests are green before the migration starts
* A working development environment is available

[#migration-steps-before-angular-22]
== Migration Steps before upgrading to Angular 22

To keep the migration verifiable on a single framework version at a time, complete the following steps before upgrading to Angular 22.
The name of any change opens a detailed migration guide with instructions, code examples, and explanations.

[#upgrade-to-angular-22]
== Upgrade to Angular 22

After completing the pre-migration steps, proceed with upgrading the application to Angular 22.

If the project is an NX workspace, follow the instructions in xref:./update-nx-angular-version-22.adoc[Upgrade NX Application to Angular 22]. After completing the NX migration steps, also review the official Angular update guide for any additional steps or considerations: https://angular.dev/update-guide?v=21.0-22.0[Angular Update Guide].

If the project is not an NX workspace, follow the official Angular update guide to perform the version upgrade by following this link: https://angular.dev/update-guide?v=21.0-22.0[Angular Update Guide].

[%interactive]
** [ ] xref:./update-nx-angular-version-22.adoc[Upgrade the toolchain to Angular 22]
** [ ] xref:./keep-build-angular-22-2-3-and-webpack.adoc[Keep build-angular at 22.2.3 and webpack at 5.111.0]
** [ ] xref:./update-onecx-libs-v9.adoc[Update the OneCX UI libraries to v9]
