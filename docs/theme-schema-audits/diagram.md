# Diagram Theme Schema Audit

## Structure

- `diagram`
  - `container`: dependency `nothing`; specific; `background`, `color`
  - `header`: dependency `nothing`; specific; `font`
  - `description`: dependency `nothing`; specific; `font`
  - `selectButton`: dependency `nothing`; generic with independent minimal tokens; `gap`, `border`, `button`
    - `button`: `background`, `border`, `color`, `icon`
    - `button.hover`, `button.selected`, `button.focus`: `background`, `border`, `color`, `icon.color`
  - `footer`: dependency `nothing`; specific; `font`

No diagram-level variant, state, or severity wrappers are needed.

## Gap Analysis And Changes

- Replaced `container.bgContrast` with direct `container.background` and `container.color` tokens, and updated CSS-rule paths.
- Replaced the full embedded `selectbutton` usage with the confirmed independent minimal token set.
- Renamed the mapped select-button checked state to `selected`.
- Preserved mandatory defaults for the container, typography, and all mapped select-button base and interaction tokens.
- Replaced the legacy exact-object schema assertion with a full resolved-default snapshot and shape/default parity check.

## Default Values

`container` defaults to the surface background and contrast primitives. `header`, `description`, and `footer` default their mapped font family, size, and weight to global font primitives. `selectButton` defaults its base, hover, selected, and focus tokens to the corresponding default-variant or primary-variant primitive paths.

## Testing

The diagram spec was replaced with the three top-level schema tests: empty-object parsing, a full `parse({})` snapshot, and shape/default parity. No subcomponent spec files were added. The snapshot is generated by the test runner rather than hand-edited.
