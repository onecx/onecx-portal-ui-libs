# Accordion Theme Schema Audit

## Confirmed Structure

- Accordion: aggregator with no visual tokens.
  - Panel: independent, specific child.
    - Header: state-dependent, specific child.
      - Toggle icon: state-dependent, specific child.
    - Content: state-dependent, specific child using an independent minimal token set.

## Applied Changes

- Replaced the class-based schemas with optional shapes and composed defaults.
- Moved visual tokens below `defaultVariant.panel.defaultVariant` and placed header/content below panel states.
- Modeled panel `defaultState`, `active`, and `disabled` states; only the baseline and active header values carry defaults.
- Removed unused root tokens and unconsumed legacy settings.
- Updated PrimeNG mapping rules for the restructured paths.
- Replaced the legacy Accordion spec with a single top-level parse, snapshot, and shape/default-parity test.

## Defaults

- Panel baseline: border width and color.
- Header baseline: padding, font weight, border, focus ring, color, background, toggle icon, and first/last positional tokens.
- Header hover: color, background, and toggle icon color.
- Active panel header: color, background, toggle icon color, and active last border radius.
- Content baseline: color, background, border, and padding.

## Testing

Test/spec files were intentionally replaced as part of the audit. Snapshot coverage is generated by the integration-interface test task.
