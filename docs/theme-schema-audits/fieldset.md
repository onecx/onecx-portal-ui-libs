# Fieldset Schema Audit

**Date:** 2026-09-22
**Schema files:** `libs/integration-interface/src/lib/topics/current-themes/v1/schema/fieldset/`

## Confirmed Structure

```text
fieldset
├── defaultVariant [root container]
├── content [dependency: nothing; specific]
└── legend [dependency: nothing; specific]
    └── toggleIcon [dependency: state; specific]
```

`settings` remains root-level non-visual configuration. Fieldset defines only the `defaultVariant`
slot; no named variants are consumed by the mapper. Legend declares `defaultState`, `hover`,
`focus`, `active`, and `disabled`; none declares severities, so no `defaultSeverity` wrapper is
present.

## Gaps Applied

- Moved root visual tokens beneath `defaultVariant`.
- Replaced class-based defaults with `fieldsetShape`, `fieldsetDefaults`, and
  `applyDefaultsRecursive`.
- Moved Legend baseline tokens to `legend.defaultState`; state-specific changes remain in their
  named state blocks.
- Moved ToggleIcon baseline tokens to `legend.defaultState.toggleIcon` and its hover changes to
  `legend.hover.toggleIcon`.
- Kept Content independent and Settings unchanged.
- Updated Fieldset mapper and CSS rule paths to consume the restructured token tree.

## Default Values

| Node | Baseline defaults | State deltas |
| --- | --- | --- |
| `defaultVariant` | background, border, color, padding, transition duration | none |
| `content` | padding, gap, font family/size/weight | none |
| `legend.defaultState` | background, border, color, padding, gap, font, focus ring, toggle icon | none |
| `legend.hover` | background, border color, color, toggle icon color/rotation | hover |
| `legend.focus` | background, border color, color, focus-ring color | focus |
| `legend.active` | background, border color, color | active |
| `legend.disabled` | background, border color, color, opacity | disabled |

## Testing

The legacy Fieldset spec was replaced with the single top-level snapshot test required by the audit
workflow: empty parse, full resolved default tree snapshot, and shape/defaults parity. No separate
subcomponent tests were added.

`nx test integration-interface` compiled the refactor and passed all non-Fieldset suites. Its Fieldset
snapshot failed only because the configured task sets `CI=true`, which disallows creating a missing
snapshot. The snapshot must be generated by a workspace task that runs the same test with snapshot
updates enabled; it was intentionally not hand-edited.
