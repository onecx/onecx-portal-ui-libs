= ARIA validity: attribution table

This page records who owns each remaining violation of the axe rules `aria-allowed-attr`, `aria-prohibited-attr`, `button-name` and `aria-input-field-name` (WCAG 4.1.2). It is the result of the ARIA validity sweep (audit T-23, T-38; onecx/internal-tasks#1107).

Owners:

libs:: `onecx-portal-ui-libs` (this repository). Fixed here.
fork:: `@openng/optimus-ui`, the PrimeNG fork that `main` uses. Needs a PR in the fork, or a runtime patch in libs.
PrimeNG 19:: Upstream PrimeNG, used by apps on libs v6. Fixed by upgrading the app to libs ≥ v7, or by a runtime patch.
app:: The application's own markup or configuration. Fixed in the app repository.

== Storybook (main)

Measured on the static Storybook build of `angular-accelerator` (the only library with stories): all 140 entries of type `story` in `index.json`. One of them, `mockData2` in `diagram.component.stories.ts`, is a data export that Storybook indexes as a story, so 139 real stories were checked with axe-core and only the four rules above. Each story is opened in Chromium (`iframe.html?id=<story>`), axe runs on `#storybook-root` after the story has rendered.

[cols="2,1,3", options="header"]
|===
|Rule |Violations |Notes

|`aria-allowed-attr`
|0
|

|`aria-prohibited-attr`
|0
|axe reports `aria-label` on an element without a role only as "needs review" if the element has text content. The two `span` elements in the sorting dropdown of `ocx-data-list-grid-sorting` had such an `aria-label`; it was removed, the visible text is the content that assistive technology reads. A unit test asserts that the component renders no role-less `span[aria-label]`.

|`button-name`
|0
|The icon-only toggle buttons of `ocx-data-layout-selection` (list/grid/table) and `ocx-diagram` (diagram type) have their name as visually hidden text (`.sr-only`) inside the button, which is not hidden from assistive technology. `main` needed no code change for these names: the `.sr-only` text predates this sweep. Unit tests assert the visually hidden name of every toggle button. The unit-test axe run (happy-dom) does not report a nameless custom element host with `role="button"`, so it does not cover these toggles; the Storybook axe run does.

|`aria-input-field-name`
|0
|
|===

NOTE: Wait until the story has rendered and its translations are loaded before running axe. Until the translations are loaded, the `translate` pipe returns an empty string, so a run directly after the first render can report `button-name` or `aria-input-field-name` for elements whose name is translated. This was seen on a busy machine for the sort buttons of the data table, the default buttons of the inline dialog and the page-size select of the interactive data view; a second axe run on the same page a few seconds later was clean. This state is transient and not counted above. In the final run every story was clean on the first axe run.

To re-run the measurement:

. `npx nx run angular-accelerator:build-storybook --outputDir=<dir>`
. Serve `<dir>` and, for every story in `<dir>/index.json` (entries of type `story`), open `iframe.html?id=<id>&viewMode=story` in a browser (for example with Playwright).
. Inject `node_modules/axe-core/axe.min.js` and run `axe.run(document.querySelector('#storybook-root'), { runOnly: { type: 'rule', values: [<the four rules>] } })`. The Storybook a11y addon also runs axe on the page; retry when axe reports that it is already running.

The unit tests use the same rules through `expectNoAxeViolations` (see link:./a11y-testing.adoc[Accessibility testing]).

== Decision: p-dialog close label and paginator labels

Two options exist for apps that still run libs v6 (PrimeNG 19):

. Upgrade the apps to libs ≥ v7 (preferred). The libs dialogs then pass a translated close label (onecx/internal-tasks#1100), and the paginator labels have defaults in the PrimeNG config.
. Ship a runtime patch in libs that sets a default close label and the paginator `translation.aria` keys.

The decision is open and is recorded with the PO in onecx/internal-tasks#1107; update this section when it is made. The fork PR for a default `closeAriaLabel` is tracked there as well.
